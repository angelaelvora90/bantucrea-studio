# BantuCrea Studio — Créateur de CV 📝

Créez un beau CV en quelques minutes : remplissez le formulaire à gauche,
l'aperçu se met à jour en direct à droite. 100% gratuit, sans inscription,
vos données restent dans votre navigateur.

## ✨ Fonctionnalités

- 📝 Formulaire complet : profil, expériences, formations, compétences, langues, intérêts
- 🎨 **3 modèles de CV** : Moderne, Élégant, Créatif + couleur personnalisable
- 📷 Photo de profil (optionnelle)
- 👀 Aperçu en direct
- 💾 Sauvegarde automatique dans le navigateur
- ⬇️ Export PDF + impression
- ✨ Bouton « Exemple » pour découvrir l'app avec un CV pré-rempli

## 🚀 Lancer le projet

Aucune installation nécessaire ! Choisissez une méthode :

**Méthode 1 — Ouvrir directement :**
- Double-cliquez sur `index.html` (l'export PDF nécessite internet pour la librairie)

**Méthode 2 — Petit serveur local (recommandé) :**
```bash
cd bantucrea-studio
python3 -m http.server 8000
```
Puis ouvrez http://localhost:8000 dans votre navigateur.

## 📁 Structure du projet

```
bantucrea-studio/
├── index.html   → la page : formulaire + aperçu (structure)
├── style.css    → le design : application + modèles de CV + impression
├── app.js       → le comportement : données, aperçu en direct, PDF (commenté en français)
└── README.md    → ce fichier
```
